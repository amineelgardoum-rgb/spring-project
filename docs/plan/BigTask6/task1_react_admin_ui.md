# Task 1: React Admin Components

## Description
Implement the frontend screens for the Admin role using React.

## What we should implement
- `DatasetsList.jsx`: Table showing datasets with progress bars (Calls `GET /api/admin/datasets`).
- `DatasetUpload.jsx`: Form with file input mapping to `POST /api/admin/datasets/upload`.
- `AnnotatorManagement.jsx`: CRUD UI for users mapping to `/api/admin/users`.
- `NlpDashboard.jsx`: Buttons to trigger train/test endpoints and a chart/table showing the logs.
